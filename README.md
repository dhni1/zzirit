# 노트북 접촉 전류 및 찌릿함 위험도 계산기

충전 중 금속 노트북을 만졌을 때 느껴지는 찌릿함을 실제 실험 없이 시뮬레이션하는 웹사이트입니다. 기존 Python 버전도 함께 남겨두었습니다.

## 웹사이트 실행 방법

Vercel에 올릴 때는 이 폴더 전체를 배포하면 됩니다. 로컬에서 먼저 확인하려면 다음 명령을 실행합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 다음 주소를 엽니다.

```text
http://localhost:4173
```

## Python 버전 실행 방법

```bash
python3 laptop_touch_current_simulator.py
```

콘솔에서 샘플 계산만 확인하려면 다음 명령을 사용합니다.

```bash
python3 laptop_touch_current_simulator.py --sample
```

## 프로그램 기능

1. 유도전압 `V0`, 내부 누설 경로 저항 `Rleak`, 인체 저항 `Rbody`, 접지 저항 `Rg`를 조절할 수 있습니다.
2. 접촉 전압, 인체 통과 전류, 기준 대비 감소율, 위험도 단계를 계산합니다.
3. 웹사이트에서는 4개 변수 각각에 대해 나머지 조건을 고정했을 때의 접촉전류 그래프를 볼 수 있습니다.
4. Python 버전에서는 조건별 결과를 CSV 파일로 저장할 수 있습니다.

## 안전 안내

이 프로그램은 교육용 시뮬레이션입니다. 실제 충전기, 콘센트, 노트북 외함을 분해하거나 접촉 전류를 직접 측정하는 실험은 감전 위험이 있으므로 수행하지 않습니다.
